# Internal vs External Assessment Effectiveness Study

## 📊 Project Overview

This project analyzes **Internal Assessment (IA)** and **External Examination (EE)** performance using an interactive **Power BI dashboard**.

The dashboard helps compare assessment performance, identify subject-wise patterns, analyze score gaps, and identify students who may require additional academic attention.

## 🎯 Objectives

* Compare Internal and External assessment performance.
* Analyze the relationship between IA and EE scores.
* Identify subject-wise performance gaps.
* Analyze performance across semesters and departments.
* Identify potentially at-risk students using predefined criteria.
* Present insights through an interactive dashboard.

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX**
* **Microsoft Excel**
* Data Modeling
* Data Visualization

## 📈 Dashboard Features

* **Executive Summary** – Overall academic KPIs and performance overview.
* **Subject Analysis** – Comparison of IA and EE performance by subject.
* **At-Risk Analysis** – Identification of students with high IA and comparatively low EE scores.
* **Grade Distribution** – Comparison of grade distributions.
* **Semester Trends** – Analysis of performance across semesters.
* **Department Comparison** – Comparison of performance across departments.
* **Student Details** – Detailed student-level analysis using drill-through.

## 🔄 Data Analysis Process

1. Imported assessment data from Excel.
2. Cleaned and transformed the data using Power Query.
3. Created a structured data model in Power BI.
4. Developed DAX measures for KPIs and analysis.
5. Designed interactive dashboards with filters and visualizations.
6. Analyzed assessment patterns and performance differences.

## 📊 Key Metrics

* Average IA Score
* Average EE Score
* Pass Rate
* Score Gap
* IA–EE Correlation
* At-Risk Student Count

## 🔍 Key Insights

The dashboard is designed to identify:

* Differences between Internal and External performance.
* Subjects with larger performance gaps.
* Semester-wise performance trends.
* Differences in grade distributions.
* Students who may require additional academic support.
